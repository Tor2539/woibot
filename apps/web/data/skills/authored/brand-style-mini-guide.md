# Brand Style Mini-Guide

A style guide is only useful if it fits on one page and gets used. Define roles, not just colors.

## Steps

1. Capture the brand's personality in 3-4 adjectives with one anti-adjective each (e.g. "confident, not arrogant; warm, not childish"). Every later choice must pass these filters.
2. Define the palette by role, not just hue: primary (brand presence, CTAs), secondary (supporting surfaces), accent (highlights, sparingly), neutrals (text, borders, backgrounds). Give hex/RGB values and a contrast check for text-on-background pairs.
3. Pair two typefaces max: one for headings (personality) and one for body (readability). Specify sizes for h1, h2, body, caption, and minimum size.
4. Voice: 3-5 traits with examples ("says 'thanks for flagging this' not 'we apologize for the inconvenience'"), plus a short list of words the brand never uses.
5. Imagery rules: subject matter, treatment (bright, natural, cropped tight), and what is banned (stock clichés, mismatched filters).
6. Write 2 do/don't example pairs — a good headline and a bad one, a good color use and a misuse — concrete enough to settle arguments.
7. Keep it to one page with a version note; a guide nobody can find or read is not a guide.

## Output

The one-page guide text, organized by palette, type, voice, imagery, and examples.
