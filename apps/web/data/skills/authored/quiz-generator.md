# Assessment Quiz Generator

A good quiz measures the objective, not reading comprehension of the question. Bad distractors turn assessment into guesswork.

## Steps

1. List the objectives being tested and allocate items per objective by importance. Every item traces to an objective; if one cannot be traced, cut it.
2. Build a difficulty spread: ~40% easy (confidence and warm-up), ~40% medium (real discrimination), ~20% hard (separates strong learners). Order easy to hard.
3. Write multiple-choice stems as complete questions or self-contained problems (no half-sentences); randomize correct positions; avoid "all of the above" (it rewards elimination logic, not knowledge).
4. Design distractors as realistic errors: use the mistakes learners actually make (common misconceptions, sign errors, wrong formula step). A distractor nobody would choose is decoration.
5. Ensure one defensibly correct answer per item; if experts could argue for two, rewrite rather than accept ambiguity.
6. Add open-ended items for skills MCQs cannot reach (explain, justify, show work) with a scoring rubric: full/partial/minimal credit criteria written in advance.
7. Produce the answer key with one-line rationale per item (why the key is right and where each distractor comes from) — this doubles as feedback material and an accuracy check.
8. Review for bias and clarity: no culturally specific assumptions, language level matches learners, item lengths similar between options (the longest option should not signal "correct").
