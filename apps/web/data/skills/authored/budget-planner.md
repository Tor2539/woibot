# Budget Planner and Tracker

A budget is a hypothesis about spending. Build it so reality can be compared against it, and adjust on evidence.

## Steps

1. Define the budget period and granularity: monthly for operations, by phase for projects. Line items must map to how money is actually spent (vendors, categories), not how an accountant reports it.
2. List fixed costs first (rent, salaries, subscriptions) with their known values, then variable costs with a driver and rate per driver (support cost = tickets x cost per ticket). Drivers make budgets responsive to volume changes.
3. For uncertain items, give a three-point estimate: low / expected / high, and budget the expected with a documented note on what would push it high.
4. Add a contingency line (10-20% depending on uncertainty) as its own line item — never spread invisible buffer across lines, which hides overruns.
5. Sum and sanity-check against available funds or target; if over, cut by ranking lines: cut nice-to-haves entirely before shaving must-haves thinly everywhere.
6. Record every assumption next to its line (headcount, volumes, prices) — the assumption list is what makes variance review diagnosable.
7. Set the tracking loop: monthly actual vs budget with a variance rule (investigate anything over ±10% or ±5,000), forecast the period-end from the trend, and update assumptions — not just numbers.
8. Version the file (v1 initial, v2 post-review) and keep the original intact for audit.

## Checks

- Contingency visible as a line item.
- Every estimated line has a driver or a three-point note.
