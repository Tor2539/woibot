# Poster and Flyer Design Brief

A poster gets 2-3 seconds of attention. One message, one action, zero clutter.

## Steps

1. Define in one line: the single message, the single action (visit, call, scan, attend), and the audience. Everything else is decoration — cut it.
2. Establish hierarchy in three levels and assign sizes: headline (dominant, readable at 3 meters), key detail block (when/where/price), supporting info (small print). If two elements have the same visual weight, they compete — rank them.
3. Pick a constrained palette: one dominant color, one accent, neutrals for text. Ensure text-to-background contrast ratio is at least 4.5:1 for body text.
4. Choose typography that matches tone (event = bold display face, corporate = clean grotesque); max two families, and give the headline real size (never crowd it to fit more words — shorten the headline instead).
5. Compose on a grid: strong focal point (image or headline) at top or center, clear reading path to the action, generous margins (at least 10-15% of width). Leave breathing room; emptiness is a feature.
6. Make the action unmissable: QR code large with quiet zone, or URL/phone in the key detail block with the accent color.
7. Prepare production specs: correct bleed (typically 3mm) and safe margins, 300 DPI for print or sized-for-screen pixels for digital, CMYK-safe colors for print, filename with size and version.
8. Final check at thumbnail size (shrunk to 10%): is the message still readable? If not, increase contrast or reduce content.

## Output

Design description with hierarchy, palette, typography, layout, and production specs.
