# Ad Copy Frameworks

Ads fail from vague promises, not bad grammar. Match the structure to how aware the audience already is.

## Steps

1. Place the audience on the awareness ladder: unaware of the problem, aware of the problem, aware of solutions, comparing options, or ready to buy. Structure choice follows:
   - Problem-unaware: PAS (Problem, Agitate, Solution) — open with the pain in their words.
   - Solution-shopping: Before-After-Bridge — show the transformation, then the mechanism.
   - Comparing options: AIDA with proof — interest via specifics (numbers, names), desire via differentiators.
   - Ready to buy: offer-first copy — price, deadline, guarantee up front.
2. Write the promise with a specific number or mechanism: "cut report prep from 6 hours to 20 minutes" beats "save time". Specificity is the cheapest credibility.
3. Address the single biggest objection inside the copy (guarantee, proof, social count, or a risk-reversing line).
4. Draft the required variants: 3 hooks x 2 bodies minimum, each changing exactly one variable (pain vs gain lead, mechanism vs outcome) so test results are readable.
5. Match the destination: the landing page must continue the ad's promise in its headline — click-to-page message mismatch kills conversions and wastes spend.
6. Check compliance and tone: no unverifiable claims ("best", "#1" without proof), platform policy limits, and the brand voice guide.
7. Set the test plan: primary metric (CTR for cold, conversion for warm), budget per variant, and the rule you will use to pick a winner before launching.
