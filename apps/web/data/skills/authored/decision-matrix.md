# Weighted Decision Matrix

Turn a gut-feel choice into a scoring the team can argue with and later audit.

## Steps

1. Write down the decision and the real constraint (budget, deadline, must-have capability) before scoring anything.
2. Choose 4-7 criteria that reflect the goal, mixing hard requirements (must pass or the option is disqualified) and weighted preferences. Name each criterion so two people would score it the same way.
3. Assign weights that sum to 100. Derive weights by ranking criteria, not by making them all "important".
4. Score each option 1-5 per criterion with a one-line justification per score. If a score is a guess, mark it "low confidence".
5. Disqualify first: any option failing a hard requirement is removed before weighting, no matter how attractive otherwise.
6. Compute weighted totals, then show the table with scores and justifications side by side.
7. Sensitivity check: change the top criterion's weight or the two most uncertain scores and see if the winner changes. Report which conclusion is stable and which is fragile.
8. Recommend the winner, note the strongest counterargument, and list the 1-3 facts that, if learned, would change the decision.

## Checks

- Weights sum to 100 and were ranked, not defaulted.
- Every low-confidence score is flagged.
