# On-Page SEO Audit

Rank pages by making them the best answer for a specific query. Audit against one target keyword per page.

## Steps

1. Identify each page's target keyword and search intent (informational, comparison, transactional). All on-page elements must serve that intent — a mismatch caps rankings regardless of other fixes.
2. Title tag: contains the target keyword near the front, ~50-60 characters, compelling enough to earn clicks (title = ranking input AND ad copy).
3. Meta description: ~150-160 characters, states the page's specific value with a reason to click. Not a ranking factor directly, but click-through is.
4. Heading structure: exactly one H1 containing the target keyword or a close variant; H2s break the topic into the subtopics searchers expect; no heading levels skipped for styling reasons.
5. Content relevance and depth: answers the actual question completely — compare against the current top 5 results for the keyword and note what they cover that this page misses (missing subtopics, data, examples). Add substance, not synonyms.
6. Internal linking: page receives links from related pages with descriptive anchor text, and links out to 2-5 relevant internal pages. Orphan pages get flagged.
7. Technical basics: single canonical URL, no duplicate-title pages, image alt texts present and descriptive, page loads fast enough (check Core Web Vitals if available), mobile rendering sound.
8. Produce the fix list ordered by expected impact: title/H1 fixes, content gaps to fill, link changes, technical corrections — each with the exact new text where applicable.
