# Lesson Plan Builder

Learning objectives first, activities second. A lesson without observable objectives cannot fail visibly — and so cannot improve.

## Steps

1. Write 1-3 objectives as observable behavior: "students can compute a 15% discount without a calculator", not "understand percentages". Each objective gets its assessment before the lesson is built (backward design).
2. Hook (5 minutes): open with a problem, question, or surprising example that makes the skill's usefulness obvious. Save the definition for after the learner sees why it matters.
3. Model the skill explicitly: work one full example aloud, thinking through decisions, then a second example with the learner(s) contributing decisions.
4. Guided practice: learners attempt similar problems while help is close at hand; check every attempt and correct immediately. Design 3-5 items of increasing difficulty.
5. Independent practice: learners work alone; you circulate and note error patterns. Include one stretch challenge for fast finishers that extends, not just adds volume.
6. Checks for understanding throughout: mini-whiteboards, quick writes, or one-question polls at each phase — not only at the end. Plan what you will do if 30% miss the check (re-teach differently, not louder).
7. Close with retrieval: 2-3 questions from today plus one from a previous lesson (spacing matters), and state next lesson's link.
8. Timing table per phase with a contingency: what to cut if running late (never the checks; cut extension material).

## Checks

- Objectives observable; assessments match objectives.
- A plan for both fast finishers and strugglers exists.
