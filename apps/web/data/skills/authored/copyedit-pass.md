# Copyedit and Clarity Pass

Edit in three separate passes. Mixing them makes each pass weaker.

## Steps

1. Structure pass: read only the headings and first sentences in order. Does the document flow logically? Move or cut whole sections before touching sentences.
2. Clarity pass, sentence by sentence:
   - Replace passive voice when the actor matters ("We shipped the fix", not "The fix was shipped").
   - Cut filler: "in order to" becomes "to"; "due to the fact that" becomes "because".
   - One thought per sentence; split anything over ~30 words.
   - Prefer concrete nouns over abstractions ("delivery delays" not "operational challenges").
3. Consistency pass: one spelling variant, one tense for past events, one format for dates, numbers, and units; matching terminology (do not alternate between "client" and "customer" for the same thing).
4. Preserve meaning: if a sentence can only be fixed by changing what it claims, flag it to the author instead of rewriting silently.
5. Final read aloud (mentally): anything you stumble on, the reader will too.

## Output

Return the edited text, then a short list of substantive changes or open questions, separated clearly.
